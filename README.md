## 🌟 About the Project

**Namma Pustaka** is a beginner-friendly Library Management System developed using Python, Flask, HTML, CSS, and SQLite.

The project helps users manage books digitally instead of maintaining library records manually. It provides a simple way to add books, view available books, and organize a collection of educational books, mythology, and traditional stories.

🎯 **Main Goal:** To make library management simple, organized, and user-friendly.

## ✨ Key Features

- 📚 **Add Books** – Add new books to the library.
- 🔍 **View Books** – Display the available book collection.
- 📝 **Manage Book Details** – Organize book information.
- 💾 **SQLite Database** – Store book records.
- 🌐 **Web Interface** – Access library features through a browser.
- 🎨 **Simple User Interface** – Easy-to-use pages built with HTML and CSS.
- ⚡ **Flask Backend** – Handle web requests using Python.

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/poodisuresh-078/Namma-Pustaka.git
```

### 2️⃣ Open the Project Folder

```bash
cd Namma-Pustaka
```

### 3️⃣ Install Flask

Make sure Python is installed, then run:

```bash
python -m pip install flask
```

### 4️⃣ Run the Application

```bash
python app.py
```

### 5️⃣ Open in Your Browser

Visit:

```text
http://127.0.0.1:5000/
```

🎉 **Congratulations! Your Namma Pustaka application is ready to run.**

*Note: These commands assume that `app.py` starts the Flask application and that the database setup is handled by your project code.*
